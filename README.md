# WBboard

Аналитика продаж Wildberries: live P&L, юнит-экономика, остатки и поставки, аналитика рынка (MPstats), фото-чек.
Документация и ТЗ: Obsidian vault `projects/WBboard/` (метрики — `files/50-metrics-spec-10x.md`,
эталон UI — `files/prototype/wbboard-prototype.html`, UX и роли — `files/60-ux-cabinets.md`).

## Быстрый старт (локально)

```bash
docker compose up -d db
cp .env.example .env        # AUTH_SECRET / TOKEN_KEY: openssl rand -hex 32
npm i
npx prisma db push
npm run seed                # роли, пользователи, демо-данные (60 дней)
npm run dev                 # UI на :3000
npm run worker              # коллекторы по расписанию (второй терминал)
```

Вход: `admin@wbboard.local / wbboard123` (или SEED_ADMIN_PASSWORD из .env).
Деплой на VPS — см. `DEPLOY.md` (docker compose up -d --build поднимает всё разом).

## Модули

| Страница | Что делает |
|---|---|
| Пульс | плитки периода, динамика, алерты, свежесть коллекторов |
| РНП | заказы/выкупы/реклама/ДРР по дням |
| P&L · ОПиУ | водопад месяца, live-оценка против факта финотчёта v5 |
| Товары | юнит-экономика по SKU, ввод партий COGS |
| Реклама | кампании fullstats v3, CTR/ДРР |
| Остатки и поставки | остатки WB + история, мой склад, закупки (Китай→карго→приёмка с авто-COGS), отгрузки на WB со сверкой приёмки |
| Аналитика рынка | MPstats: ниши, конкуренты, ключи; мок-режим до покупки ключа (вставить в Настройках) |
| Акции | калькулятор входа в акцию «до/после» |
| Финансы | финотчёты, косвенные расходы, курсы валют |
| Настройки | кабинеты + WB-токены (AES-GCM), интеграции, роли, ручной запуск коллекторов |
| Фото-чек | фото → ключи/категория → цена 1688 → вердикт «вход интересен при закупке ≤ X ₽» (мок до фазы 3) |

## Структура

- `prisma/schema.prisma` — БД: кабинеты/RBAC, сырьё WB, COGS-партии, поставки (ЗК/склад/отгрузки), MPstats-витрины, PhotoCheck
- `src/collectors/*` — коллекторы WB API + fx + mpstats
- `src/worker.ts` — pg-boss: 11 очередей, heartbeat, TG-алерты
- `src/lib/` — auth (RBAC), crypto (токены), pl.ts (запросы дашбордов), metrics/unit.ts (юнит-экономика, УСН+НДС/ОСНО, FX-репрайс), mpstats/ (клиент+мок), photocheck/ (пайплайн)
- `src/app/` — Next.js App Router, дизайн из утверждённого прототипа

## Роли (seed)

Собственник (всё, деньги A) · Менеджер МП (B) · Трафик (C) · Финансист (A) · Закупки (C).
